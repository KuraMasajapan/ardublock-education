# ArduBlock Education Edition

Version: 0.1.0-alpha

## Vision

ArduBlock Education Edition is a modern educational visual programming environment
for Arduino IDE 1.8.x.

This project aims to make Arduino programming accessible to everyone,
especially elementary school students, beginners, teachers, and makers.

Unlike the original ArduBlock, this edition focuses on usability,
clear language, educational content, and long-term maintainability.

---

## Goals

- Easy enough for children
- Friendly to Scratch users
- Compatible with Arduino IDE 1.8.x
- Compatible with Arduino Uno/Nano/Mega/Leonardo/UIAPduino
- Beautiful modern interface
- Japanese and English localization
- Educational examples included

---

## Non Goals

This project does NOT attempt to replace Arduino IDE.

It is an educational extension for Arduino IDE.

---

## Target Users

- Elementary school
- Junior high school
- High school
- Universities
- Makers
- Teachers
- Robotics clubs

---

## Development Principles

1. Education first
