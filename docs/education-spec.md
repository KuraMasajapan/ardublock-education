# ArduBlock Education Edition Specification

Version: 0.1 Alpha

---

# Vision

ArduBlock Education Edition is a modern educational visual programming environment based on the classic ArduBlock project.

Our goal is not to imitate Scratch.

Our goal is to make Arduino easier to understand.

---

# Target Users

Primary

- Elementary school students
- Junior high school students
- High school students

Secondary

- Teachers
- Makers
- Beginners

---

# Design Principles

## Education First

Every function should be understandable.

Do not expose unnecessary complexity.

---

## Simple

Use familiar Japanese.

Avoid technical jargon whenever possible.

---

## Learn While Using

Important Arduino API names should remain visible.

Example

LEDをつける

digitalWrite()

---

## Compatible

Compatible with

- Arduino UNO
- Arduino Nano
- Arduino Mega
- UIAPduino
