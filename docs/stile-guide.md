# Style Guide

## Philosophy

Education First.

Everything should be understandable by elementary school students.

---

## Naming

Use natural Japanese.

Examples

LEDをつける

LEDを消す

ボタンを読む

文字を書く

画面に表示する

---

## English API

Keep Arduino API names visible.

Example

LEDをつける

digitalWrite()
